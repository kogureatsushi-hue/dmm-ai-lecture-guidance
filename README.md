## 講座概要作成の共通フロー

以下は既存手順書に記載された運用方針です。今回、その実装が同梱されたという意味ではありません。

1. 講座資料PDFとワーク使用ファイルの両方を確認する。
2. 講座時間・休憩・演習時間・保存先などの未確定事項を確認する。
3. Markdownの作業プレビューを作成する。
4. 利用者が内容を承認する。
5. DOCXへ変換し、表・見出し・改ページなどを確認する。
6. 指定した保存先へ保存し、保存結果を確認する。

講座概要の見出しは「講座の概要」「章構成」「タイムテーブル」「ポイント」「注意点」の5つです。演習とハンズオンを区別し、タイムテーブルの内容列には演習名と受講生の実施時間を含めます。資料にない講座固有情報を推測で追加しません。

## 変更・問い合わせ

変更は作業ブランチで行い、Pull Requestで差分を確認してからmainへ反映します。原本の追加時にも、既存ファイルを無条件に置き換えず差分を確認してください。

不具合・不足情報はIssueへ記載してください。使用環境、対象バージョンまたはコミット、期待した結果、実際の結果、機密情報を除いたエラー内容を添えます。認証情報や受講生の個人情報は登録しません。
