# ChatGPT Workでの使い方

## この文書について

この文書は、講座資料（PDF）とGoogle Drive上のワーク使用ファイルをもとに、講師共有用の「講座概要」を作成するSkillの利用手順をまとめたものです。

プラグインの表示名は「DMMビジネスAI研修｜講座概要作成プラグイン」、Skillの表示名は「講座概要作成」、Skill IDは`course-overview-generator`です。

共有元：`https://github.com/kogureatsushi-hue/dmm-ai-lecture-guidance`

## 想定する利用環境

- ChatGPT Workを利用できること
- ワークスペース管理者が「DMMビジネスAI研修｜講座概要作成プラグイン」を利用可能にしていること
- Google Driveプラグインが利用でき、対象フォルダを閲覧・編集できること
- 講座資料のPDFと、ワーク使用ファイルの保存場所が確認できること

## ChatGPT Workでの共有方法

チーム利用では、Skillを含むプラグインをPrivateなGitHubリポジトリで管理し、ワークスペース管理者がリポジトリ内のマーケットプレイスを読み込む方式を想定します。

本運用では、利用者全員にGitHubリポジトリの閲覧権限を付与します。利用者はREADME、利用手順、Skill、更新履歴を自分で確認できます。管理者とリアルタイムに連携できない場合でも、GitHub上の情報を参照して導入やトラブル確認を進められる状態を目指します。

ただし、GitHubリポジトリを閲覧できるだけでは、ChatGPT Work上でSkillは有効になりません。ワークスペース管理者によるマーケットプレイスの初回インポートと利用ポリシー設定が必要です。初期設定後は、利用者がChatGPT Work上でプラグインをインストールして利用します。

### 用語の違い

| 名称 | 役割 | 利用者が行うこと |
|---|---|---|
| GitHub | Skill、手順書、更新履歴などを保管・共有する場所 | 招待を承認し、READMEや手順書を確認する |
| DMMビジネスAI研修｜講座概要作成プラグイン | 管理者がGitHubからChatGPT Workへ登録する機能一式 | ChatGPT Workのプラグイン一覧でこの名前を検索し、必要に応じてインストールする |
| 講座概要作成Skill | 講座概要を作成するための具体的な手順。Skill IDは`course-overview-generator` | 新しいチャットで「@」から「講座概要作成」を選択して使用する |

利用者がChatGPT Workのプラグイン一覧で探すものは、**GitHubではなく「DMMビジネスAI研修｜講座概要作成プラグイン」**です。

## GitHubアクセスからSkill有効化まで

### 全体フロー

| 手順 | 実施者 | 内容 | 完了条件 |
|---:|---|---|---|
| 1 | リポジトリ管理者 | 対象者をPrivateリポジトリへ招待する | 招待を送信済み |
| 2 | 利用者 | GitHubから届いた招待を承認する | リポジトリをブラウザで開ける |
| 3 | 利用者 | READMEと「ChatGPT-Workでの使い方」を確認する | 必要な入力資料と作業手順を把握した |
| 4 | ワークスペース管理者 | GitHubのマーケットプレイスをChatGPT Workへインポートする | 「DMMビジネスAI研修｜講座概要作成プラグイン」が管理画面に表示される |
| 5 | ワークスペース管理者 | 対象者のロールまたはグループへ利用を許可する | 利用者側でプラグインを確認できる |
| 6 | 利用者 | ChatGPT Workで「DMMビジネスAI研修｜講座概要作成プラグイン」をインストールする | インストール済みと表示される |
| 7 | 利用者 | 新しいチャットで「講座概要作成」を選択する | 「@」の候補にSkillが表示される |
| 8 | 利用者 | 動作確認用の依頼を実行する | Skillが質問またはMD作成フローを開始する |

### 1. GitHubの招待を承認する

リポジトリ管理者から招待が届いたら、利用者は自分のGitHubアカウントで承認します。承認後、共有されたリポジトリURLをブラウザで開き、READMEと「docs」フォルダを閲覧できることを確認します。

一般利用者には原則として閲覧権限を付与します。Skillや手順書を更新する担当者だけに、書き込み権限を付与します。

### 2. 必要に応じてリポジトリをダウンロードする

ChatGPT Workだけを利用する場合、Skillファイルのダウンロードは必須ではありません。ただし、手順書や更新履歴をオフラインでも確認したい場合は、「Code」からZIPをダウンロードできます。

ローカルCodexでも使用する場合は、ZIPではなくGitでのcloneを推奨します。更新時に最新版を取得しやすいためです。詳しくは「ローカルCodexでの使い方」を参照してください。

### 3. 管理者の初期設定完了を確認する

管理者は、利用者を招待する前または並行して、マーケットプレイスのインポートと利用ポリシー設定を行います。利用者はREADMEに記載された「利用開始可能」の状態、「DMMビジネスAI研修｜講座概要作成プラグイン」とSkill名を確認します。

管理者とのリアルタイム連携を前提にしないため、リポジトリのREADMEへ次を記載します。

- ChatGPT Workへのインポート状況
- 利用可能な対象者またはグループ
- ChatGPT Workで検索するプラグイン名と、チャットで選択するSkill名
- 最終同期日とバージョン
- 問い合わせ方法

### 4. ChatGPT Workで「DMMビジネスAI研修｜講座概要作成プラグイン」を有効にする

ここで探すのは「GitHub」ではありません。GitHubは、Skillや手順書を保管している場所です。

ChatGPT Workで利用者が探すのは、管理者がGitHubから登録した「DMMビジネスAI研修｜講座概要作成プラグイン」です。

1. ChatGPT Workでプラグイン一覧を開く。
2. 「DMMビジネスAI研修｜講座概要作成プラグイン」を検索する。
3. 「インストール」または「追加」を選ぶ。
4. 新しいチャットを開き、「@」から「講座概要作成」を選べることを確認する。

管理者が利用者へインストール済みの状態で配布した場合は、手順2～3が不要になることがあります。その場合も、手順4でSkillが表示されることを確認してください。

### 5. Skillの有効化を確認する

新しいチャットを開き、「@」から対象Skillを検索します。Skillが選択できたら、次の確認用プロンプトを実行します。

~~~text
講座概要作成の開始前チェックをしてください。
まだ資料の作成やGoogle Driveへの保存は行わず、必要な入力情報だけを一覧で示してください。
~~~

必要なPDF、ワーク使用ファイル、出力先、講座時間などが提示されれば、有効化確認は完了です。この確認では実ファイルを作成しません。

### 管理者が行う初期設定

1. GitHub上の対象リポジトリを開けるアカウントを用意する。
2. ChatGPT Workの管理画面で「Plugins」を開く。
3. 「Add」から「Import marketplace」を選ぶ。
4. GitHubリポジトリのURLとして`https://github.com/kogureatsushi-hue/dmm-ai-lecture-guidance`を入力する。
5. `.agents/plugins/marketplace.json`はリポジトリ直下にあるため、Pathは空欄にする。Branchは承認済みの`main`を指定する。
6. GitHubへのアクセスを承認してインポートする。
7. インポート結果を確認し、「DMMビジネスAI研修｜講座概要作成プラグイン」の利用対象者とインストールポリシーを設定する。
8. Google Driveプラグインが対象メンバーに許可されていることを確認する。

Privateリポジトリを使用する場合、連携に使うGitHubアカウントには、そのリポジトリの読み取り権限が必要です。Organization側の承認が必要な場合は、事前に完了させます。

## 利用前に準備するもの

| 項目 | 必須 | 内容 |
|---|---:|---|
| 講座資料 | 必須 | 講座内容が記載されたPDF。チャットへ添付するか、閲覧可能なDriveリンクを指定する |
| ワーク使用ファイル | 原則必須 | プロンプト雛形、演習ファイル、完成見本などを格納したGoogle Driveフォルダ |
| 出力先 | 必須 | 講座概要MDとDOCXを保存するGoogle Driveフォルダ |
| 講座時間 | 確認推奨 | 3時間、2時間など。資料から判断できない場合は利用者が指定する |
| 個別条件 | 任意 | 演習時間、対象者、講師への注意事項など、資料にない確定情報 |

## 基本的な使い方

### 1. 新しいチャットを開始する

講座ごとに新しいチャットを作成します。別講座の固有情報が混ざらないよう、複数講座を同じチャットで同時に処理しないことを推奨します。

### 2. Skillを指定して依頼する

ChatGPTでは「@」からSkillを選択できます。「講座概要作成」を選んでから、次のように依頼します。

~~~text
講座概要を作成してください。

講座資料：添付のPDF
ワーク使用ファイル：＜Google DriveフォルダURL＞
出力先：＜Google DriveフォルダURL＞
講座時間：3時間

最初にMarkdownで作業プレビューを作成し、私の確認が終わるまでDOCXには変換しないでください。
不明な演習時間や講座固有の条件は、推測せずに質問してください。
~~~

資料がDriveにある場合は、PDFのリンクも指定できます。ただし、リンク先の閲覧権限がないと内容を確認できません。

### 3. 資料の読み取り結果を確認する

Skillは、次の情報を整理します。

- 講座名、対象者、到達目標
- 章構成と各章の内容
- 演習、ハンズオン、講師デモの区別
- 使用するワークファイル
- タイムテーブル
- 講師が押さえるポイントと注意点
- 資料間の表記揺れ、不足ファイル、矛盾

PDFやワーク使用ファイルだけでは確定できない事項がある場合、Skillから質問が提示されます。

### 4. 質問に回答する

特に次の項目は、資料だけでは確定できないことがあります。

- 講座全体の時間
- 休憩時間と回数
- 受講生が単独で操作する演習時間
- ハンズオンを演習時間として扱うか
- 時間内に完了しない場合の扱い
- 使用するアカウント、プラン、AIモデル
- 講師から事前に案内する内容

未確定の演習時間は5分で仮置きできますが、DOCX作成前に確定することを基本とします。

### 5. Markdownの作業プレビューを確認する

講座概要は、次の5見出しで作成します。

1. 講座の概要
2. 章構成
3. タイムテーブル
4. ポイント
5. 注意点

確認時は、少なくとも次の点をチェックします。

- PDFの章構成と一致しているか
- ワークファイル名と保存場所が正しいか
- 演習とハンズオンが区別されているか
- 演習名と受講生の実施時間がタイムテーブルの内容列に入っているか
- 講座時間、休憩、各区分の合計が一致しているか
- 資料にない情報を事実として追加していないか
- 講師が事前に伝える内容が不足していないか

修正が必要な場合は、対象箇所と変更内容を具体的に伝えます。

### 6. DOCX作成を承認する

Markdownの内容が確定したら、次のように依頼します。

~~~text
内容を確定します。DOCXを作成し、レイアウトを確認したうえで指定のGoogle Driveフォルダへ保存してください。
~~~

SkillはDOCXを生成し、表の崩れ、改ページ、見出し、箇条書きなどを確認してから保存します。

## 標準の確認ゲート

| ゲート | 利用者の確認内容 | 次へ進む条件 |
|---|---|---|
| 資料確認 | PDFとワークファイルが揃っているか | 必要な資料へアクセスできる |
| 不明点確認 | 演習時間や講座固有条件 | 主要な未確定事項へ回答済み |
| MD確認 | 内容、構成、時間、注意点 | 利用者が内容を承認した |
| DOCX確認 | 見た目とページ構成 | レイアウト上の問題がない |
| 保存確認 | ファイル名と保存先 | 指定フォルダへの保存を確認した |

## トラブル時の確認

### Skillが表示されない

- GitHubの招待を承認し、リポジトリのREADMEを閲覧できるか確認する。
- READMEで、ChatGPT Workへのインポート状況と対象バージョンを確認する。
- 「DMMビジネスAI研修｜講座概要作成プラグイン」がワークスペースへインポートされているか確認する。
- 自分が利用対象のロールまたはグループに含まれているか確認する。
- プラグインをインストール後、新しいチャットで再度確認する。
- 管理者へ最新のGitHub版が同期されているか確認する。

### Google Driveの内容を読めない

- ChatGPTで使用しているGoogleアカウントを確認する。
- PDF、ワークフォルダ、出力先フォルダの共有権限を確認する。
- 共有ドライブや他人所有フォルダの場合、自分に必要な権限があるか確認する。

### タイムテーブルの合計が合わない

DOCX化を止め、講座全体の時間、休憩、各章、冒頭・まとめの配分を再確認します。演習時間は章全体の時間とは別に加算せず、章内訳として扱います。

### 資料にない内容が入っている

根拠となるPDFページまたはファイル名を確認し、根拠がなければ削除します。他講座のサンプルに記載された固有情報を転用しません。
