# ChatGPT Workでの使い方

> **状態：利用開始前のガイドです。** このリポジトリにはプラグイン本体が未収録です。まず[README](../README.md)の状態を確認してください。以下のインポート・インストール・実行は、本体の追加と確認が終わってから行います。

## 目的と名称

講座資料PDFとGoogle Drive上のワーク使用ファイルをもとに、講師共有用の講座概要を作成します。

| 名称 | 役割 |
|---|---|
| GitHubリポジトリ | 手順書・Skill・更新履歴などの共有元 |
| DMMビジネスAI研修｜講座概要作成プラグイン | ChatGPT Workへ登録する機能一式の表示名 |
| 講座概要作成 | Skillの表示名 |
| `course-overview-generator` | Skill ID |

リポジトリを閲覧できることと、ChatGPT Workでプラグインを使えることは別です。プラグインの導入は、Google Driveの閲覧・編集権限やアカウント認証を代わりに付与するものではありません。

## GitHubアクセスから有効化まで

| 手順 | 担当 | 行うこと・確認結果 |
|---|---|---|
| 1 | リポジトリ管理者 | 対象者をPrivateリポジトリへ招待し、実際の権限を確認する |
| 2 | 利用者 | 招待を承認し、READMEとdocsを開けることを確認する |
| 3 | 登録担当者 | プラグイン本体・配布用JSON・参照ファイルを追加し、参照先を検証する |
| 4 | ワークスペース管理者 | マーケットプレイスをインポートし、対象者の利用設定と必要なアプリを確認する |
| 5 | 利用者 | プラグイン一覧で正式名称を検索し、必要に応じてインストールする |
| 6 | 利用者 | 新しいチャットで利用可能な選択操作を使って「講座概要作成」を指定する |
| 7 | 利用者 | 下記の確認用依頼を実行し、必要な入力情報を案内できることを確認する |

管理者がインストール済みで配布した場合は、利用者による追加インストールは不要です。表示・利用可否は実際のワークスペースで確認してください。

### 管理者向け：本体追加後のインポート設定

2026年9月5日に確認したOpenAI公式案内に基づく手順です。

1. Workspace settings → Plugins → Add → Import marketplaceを開く。
2. Sourceに `https://github.com/kogureatsushi-hue/dmm-ai-lecture-guidance` を入力する。
3. Pathは配布用manifestの実際の配置に合わせる。リポジトリ直下に `.agents/plugins/marketplace.json` を置いた場合は空欄にする。ファイル名そのものは入力しない。
4. Branch, tag, or commitは運用対象を指定する。mainの内容が承認済みの場合にmainを使う。
5. GitHubへのアクセスを認証し、インポート結果と各プラグインの利用設定を確認する。

**現在は必要ファイルが未収録のため、この操作をまだ実行しないでください。** GitHub連携とプラグインのマーケットプレイス登録も別の操作です。

## 講座概要を作成する

### 1. 入力資料を用意する

最新版の講座PDF、ワーク使用ファイルの保存場所、講座時間、休憩、成果物の保存先を用意します。Google Drive上の資料と保存先へアクセスできることを確認します。

### 2. Markdown作成を依頼する

```text
講座概要を作成してください。
講座資料：添付のPDF
ワーク使用ファイル：＜Google DriveフォルダURL＞
講座時間：＜全体時間＞
休憩：＜回数と時間＞
出力先：＜Google DriveフォルダURL＞

PDFとワーク使用ファイルの両方を確認してください。
資料から確定できない演習時間などは質問してください。
最初に作業プレビューMDを作成し、私の承認までDOCXは作成しないでください。
```

### 3. 質問に回答し、Markdownを確認する

5見出し「講座の概要」「章構成」「タイムテーブル」「ポイント」「注意点」があるか確認します。章構成、ワークファイル名、演習とハンズオンの区別、演習名と実施時間、休憩を含めた合計時間、資料にない情報の混入も確認します。

### 4. DOCX化を承認する

```text
内容を確定します。DOCXを作成し、表・改ページ・見出しなどのレイアウトを確認してください。
問題がなければ、指定したGoogle Driveフォルダへ保存し、保存結果を知らせてください。
```

保存機能や権限が使えない場合は、その状況を確認します。保存できていないものを保存済みとして扱いません。

## 確認ゲート

| ゲート | 次へ進む条件 |
|---|---|
| 資料確認 | PDFとワークファイルを確認できる |
| 不明点確認 | 時間や講座固有条件を確認できる |
| MD確認 | 利用者が内容を承認した |
| DOCX確認 | 表・見出し・改ページに問題がない |
| 保存確認 | 指定した場所への保存結果を確認した |

## 表示されない・動かないとき

まずREADMEの本体登録・検証状況を確認します。本体が未収録の段階で、再インストールや認証変更を繰り返さないでください。登録後の問題は、利用中のワークスペース、プラグインのインポート結果、対象者への利用設定、Google Driveのアクセスを順に確認します。
