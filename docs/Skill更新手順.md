# Skill更新手順

## この文書の範囲

講座概要作成Skill（`course-overview-generator`）を安全に更新するための運用ガイドです。既存の同名手順書から確認できた方針を整理したもので、原本の全文コピーではありません。

**現在のリポジトリはガイドの初回登録段階です。Skill本体・配布用JSON・テンプレート・スクリプトは未収録です。** 最初に[初回登録チェックリスト](初回登録チェックリスト.md)を確認してください。

## 基本方針

- Privateリポジトリを共有元とし、公開範囲・対象者・権限を管理者が確認する。
- 作業ブランチで変更し、レビュー後にmainへ反映する。
- 利用者の端末内だけを編集して、共有元と内容が分かれる状態にしない。
- 共通ルールと講座固有の情報を分ける。
- PDFやワークファイルの根拠を優先し、完成サンプルの製品名・時間・注意事項を別講座へ流用しない。
- ChatGPT WorkとローカルCodexの両方で動作を確認する。
- 出力形式の変更では、MarkdownだけでなくDOCXの見た目も確認する。

## ファイルごとの役割（本体追加後）

| 更新対象 | 内容 |
|---|---|
| SKILL.md | 利用条件、入力、処理順、質問・停止条件 |
| references/ | 講座概要の構成、時間配分規則、確認基準 |
| assets/ | Markdown・DOCXのひな形や固定部品 |
| scripts/ | 時間計算、変換、検証などの処理 |
| examples/ | 完成イメージ、回帰確認用サンプル |
| docs/、README.md | 利用・更新手順、導入状況、既知の問題 |
| 配布用JSON | プラグイン情報と配布対象 |
| CHANGELOG.md | 実施した変更と検証結果 |

これは役割の整理であり、上記の全ファイルが現在収録されていることを示しません。

## 更新の流れ

### 1. 変更理由と影響範囲を整理する

対象ファイル、変更理由、対象環境、既存出力への影響を明確にします。資料にある不整合を修正する場合は、元の記載と変更理由を残します。

### 2. 作業ブランチで変更する

対象ブランチの最新状態を確認し、元ファイルを読んでから変更します。既存ファイルの削除や上書き、重複Skillの整理を無条件に実行しません。

### 3. 参照先と内容を確認する

Skill ID、ディレクトリ、参照ファイル、配布用JSON、利用手順書のパスが一致しているか確認します。今回の初回登録では、原本未取得のファイルを推測で再作成しません。

### 4. 動作テストを行う

| テスト | 確認内容 |
|---|---|
| 明示呼び出し | Skill名を指定して動作する |
| 間接呼び出し | 対象業務を認識できる |
| 入力不足 | 不足情報を推測せず確認する |
| 対象外の依頼 | 関係のない処理を開始しない |
| 境界ケース | 資料の矛盾・欠損・複数版に適切に対処する |

講座概要の回帰確認では、次を確認します。

- PDFとワーク使用ファイルの両方を確認している。
- 「講座の概要」「章構成」「タイムテーブル」「ポイント」「注意点」の5見出しがある。
- 演習とハンズオンを区別している。
- 演習名と受講生の実施時間がタイムテーブルの内容列にある。
- 未確定の時間を確定値として扱わず、利用者に確認している。
- 講座全体、休憩、各区分の合計が一致する。
- Markdownの承認前にDOCXを作成していない。
- 資料にない講座固有情報を追加していない。
- DOCXの表、改ページ、見出し、余白が崩れていない。
- 指定した保存先以外へ書き込んでいない。

未実施のテストは「未実施」と記録し、ファイルを追加できたことだけで実行確認済みとしません。

### 5. 手順書・更新履歴を更新し、レビューする

変更した仕様に合わせてREADMEと手順書も更新します。配布バージョンと変更履歴は実際の変更に対応させます。既存資料の「0.1.0」という記載だけを根拠に、未取得のパッケージを検証済みとしてリリースしません。

Pull Requestには、変更理由、変更ファイル、実施したテスト、未実施の項目、残る問題を記載します。レビュー後にmainへ反映します。

### 6. 利用環境への反映を確認する

ChatGPT Workへ配布している場合は、管理者が対象マーケットプレイスの同期結果と各プラグインの利用設定を確認します。GitHubの変更と同期結果は別々に確認します。ローカルCodexでは、採用した導入方式に合わせて更新し、対象バージョンを確認します。

今回の初回登録では、ワークスペースへのインポート・同期・利用者招待・権限変更は行いません。

## READMEで管理する情報

プラグイン名、Skill名とID、本体の収録状況、対象バージョン、最終確認日、利用手順、インポート・同期状況、既知の問題、問い合わせ方法を記載します。

## 出典と追加確認

主な出典は既存の「Skill更新手順.md」です。ワークスペース側の同期については、2026-09-05に確認した[OpenAI公式案内](https://help.openai.com/en/articles/20001504-importing-and-syncing-plugin-marketplaces-from-github)を参照しています。個別ワークスペースでの操作結果を示すものではありません。
